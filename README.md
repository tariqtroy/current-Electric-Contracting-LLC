# Current Electric Contracting, LLC - One Page Landing Page

Upload `index.html`, `style.css`, `robots.txt`, and `sitemap.xml` to the root of a GitHub Pages repository.

Before publishing, replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `index.html`, `robots.txt`, and `sitemap.xml` with the real GitHub Pages URL.

The page uses natural-looking remote electrical-service images from Unsplash. Replace the image URLs with local files if you want all images bundled in the repository.
